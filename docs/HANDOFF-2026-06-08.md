### THE FRAME ORACLE — live JIT hook (server / dynarec)
7. **Live block-entry hook on the production dynarec.** Operator's insight proven: the exact PC-hook CAN run live, WITHOUT the GDB-style breakpoint (which patches a trap opcode → recompile/trap/SMC = expensive + determinism-risky). Instead a **compile-time block-entry `GenCall`** in `core/rec-x64/rec_x64.cpp` `BlockCompiler::compile()` (after `sub(rsp, STACK_ALIGN)`, before `regalloc.DoAlloc`) — one cheap native call per hooked block entry, **READ-ONLY** (reads `Sh4cntx.r[]` + `addrspace::read*`), determinism-safe, perf-trivial. `core/hw/sh4/dyna/decoder.cpp` forces a block boundary at hooked PCs that fall mid-block. Gated `MAPLECAST_FRAME_ORACLE_HOOK` (default **OFF** → blocks byte-stock).
8. **PC-ALIAS handled.** MVC2 renders from the **P0** region (`0x0C03093C`) but the marvelous2 labels are **P1** (`0x8C03093C`) — identical low 28 bits. `mc_isHookedPC` masks `pc & 0x1FFFFFFF` to match either.
9. **Routines CONFIRMED this session:**
   - **`loc_8c03093c`** (`0x8C03093C`, "Render Main Sprite") = the **per-object PER-FRAME render**. Fires per object every in-match frame (150,541+ fires in a 22197-frame match). Reads `r4=node` → writes the world→screen transform to **`screen_x/y` @+0xE0/+0xE4** (the authoritative GPU-placement anchor). This is the **OBJ_BEGIN** marker.
   - **`loc_8c033e90`** (capture PC `0x8C033EC0`, after the quad write) = the **LOAD-TIME per-character part-atlas DECODE**, NOT per-frame. Fires ONCE at match load (frame ~2568), dumps all ~1190 parts per character into the decomp buffer `0x0CE60000` (texptr walks it, palptr=0, no screen coords). Dispatched from the cell-processor jump table `loc_8c033d78`. Gated **separately** `MAPLECAST_FRAME_ORACLE_DECODE` (off by default). **USEFUL as the part-atlas catalog** (per char: every part's w/h + texture) but **NOT the placement**.
   - The 16-byte internal quad (decode path): `w<<3@+0`, `h<<3@+2`, `attr@+4`, `texptr(r8)@+8`, `palptr(r12)@+C`, written @bank03 9275–9284, cursor `r14`. Display list lands in RAM (~`0x0C56xxxx`) then bulk-DMA'd to the TA later — **NOT the TA FIFO** (no SQ / `0x10000000` writes in the draw routines).
10. **Per-frame SCREEN quads (the anchor) — the working capture.** The per-frame screen quads (real x,y) are recovered POST-walk from the parsed TA in `serverPublish` (`ta_parse` → `rc.verts`) and attributed to the nearest OBJ_BEGIN object's authoritative `screen_xy` (160px). Output per object in `/dev/shm/mc_oracle_hook.jsonl`: `node, sprite_id, screen_xy, scale, facing, tex_src, screen_quads[{x,y,w,h,u,v,z,vram_addr,tcw,fmt,tex_wh,blend}]`. In-match gated (`0x8C289624`). **Validated:** 1105 in-match frames, 2173 objects, ~8.4 attributed screen quads/object, real x/y at the object positions. (Attract demo = only 2 character bodies → ~18% attribution; a full match with satellites/projectiles/supers populates more; unmatched → frame-level `unassigned[]` bucket.)
