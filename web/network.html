Run a node

Anyone with the ROM can host. One command on a Linux box with Docker — your node boots the game, registers, geolocates, and shows up on the map above. No account, no approval.

docker run -d --name maplecast-node --restart unless-stopped \
  --shm-size=1g \
  -p 7201:7201/tcp -p 7100:7100/udp \
  -v /path/to/mvc2-folder:/data:ro \
  -v maplecast-node:/opt/maplecast/.maplecast \
  -e MAPLECAST_NODE_NAME="my-node" -e MAPLECAST_NODE_REGION="us-east" \
  ghcr.io/t3chnicallyinclined/maplecast-node:latest
✓ Linux box (a cheap VPS is easiest) ✓ Docker ✓ One folder: your MvC2 .gdi + track files + a Dreamcast BIOS (dc_boot.bin) ✓ Ports 7201/tcp + 7100/udp open

Native clients connect immediately; serving browser viewers needs a public IP + TLS. Hosting is open & casual — ranked stays on trusted nodes.
